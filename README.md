# scalingOS · Dónde dar la charla

Landing de conferencias para la charla **scalingOS Business Calibration** de Guillermo Jaramillo (nov-2026 a dic-2027).

- `index.html`: la landing (HTML estático, sin build).
- `eventos.json`: la base. La actualiza cada semana un agente desde `~/PersonalBrain/scalingOS-charlas/run.sh`.

Animaciones: Holographic Beams (21st.dev · jahed) y Scramble Text (21st.dev · dqnamo), adaptadas a vanilla JS con la paleta scalingOS. Number ticker, spotlight card y shine text inspirados en 21st.dev.
